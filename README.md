# 🎯 Quote Generator App

Een eenvoudige React-applicatie die citaten (quotes) toont. Elke keer dat je op de knop klikt, verschijnt er een nieuwe quote.

## ⚙️ Gebruikte technologieën

- React
- React Hooks (`useState useEffect`)
- JavaScript
- CSS

## 🚀 Functionaliteit

- Toont een willekeurige quote op het scherm.
- Bij elke klik op de knop wordt een nieuwe quote weergegeven.
- Quotes worden willekeurig gekozen uit een vaste lijst.
- Gemaakt met behulp van React functionele componenten en de `useState useEffect` hook.
