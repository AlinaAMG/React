 React LinkedIn-stijl Project

Een mini LinkedIn-achtig project gebouwd met **React** waarbij gebruikers zich kunnen registreren, inloggen en profielen kunnen bekijken. Alle gebruikersgegevens worden opgeslagen in **localStorage** (er is geen backend).

 🔧 Functionaliteiten

- Registratie- en inlogformulier gemaakt met React
- Gebruikersgegevens worden opgeslagen in `localStorage`
- Na het inloggen word je doorgestuurd naar `/members`
- Op de `/members` pagina zie je:
  - Welkomstbericht voor de ingelogde gebruiker
  - Lijst van alle andere leden die eerder zijn ingelogd
  - Elke gebruiker heeft een knop "Bekijk Profiel"
- Klik je op "Bekijk Profiel", dan word je doorgestuurd naar `/profile`
- Op de `/profile` pagina zie je de informatie van die specifieke gebruiker
- Routing wordt gedaan met **React Router**

 🛠️ Technologieën

- React (functionele componenten)
- React Router DOM
- localStorage voor data-opslag
- CSS voor eenvoudige styling
