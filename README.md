React To-Do Lijst App

Dit is een eenvoudige React To-Do Lijst applicatie waarin gebruikers taken kunnen toevoegen en verwijderen. Je kunt taken beheren door ze in een formulier in te voeren, de taken in een lijst weer te geven en taken te verwijderen zodra ze voltooid zijn.

Kenmerken:

Taken toevoegen: Gebruikers kunnen een taak en een beschrijving invoeren en deze aan de lijst toevoegen.
Taken verwijderen: Gebruikers kunnen een taak verwijderen door op de knop "Done" naast de taak te klikken.
Lege velden: Na het toevoegen van een taak worden de invoervelden gewist voor de volgende taak.

Gebruikte technologieën:
React
CSS voor de styling
